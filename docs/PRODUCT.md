# 产品范围

## 定位

Blipkit 是面向独立游戏开发者的轻量桌面音频工作站。目标是让新手在 10 分钟内完成第一段游戏音频，并减少专业用户在音频导出和引擎同步上的重复操作。

## 用户

- 不熟悉乐理，但需要独立完成游戏音乐与音效的开发者
- 需要快速制作、管理并导出游戏音频资产的小型团队
- 希望用轻量工具替代完整 DAW 工作流的音频创作者

## 1.0 范围

| 模块 | 最小交付 |
| --- | --- |
| 音效生成 | 常见游戏音效预设、参数编辑、随机变体 |
| 音乐编排 | Piano Roll、基础多轨、Loop、80 个内置音色 |
| 乐理辅助 | 和弦、音阶高亮、节奏模板 |
| 工程管理 | `.bkproj`、自动保存、快照、撤销重做 |
| 资产导出 | WAV / OGG / MP3、批量导出 |
| 引擎联动 | Unity、Godot、Web |

## 明确不做

- 音频录制
- 云同步与多人协作
- 移动端
- 1.0 阶段的 VST、FMOD、Wwise 支持

## 技术边界

- Python 3.11+
- CustomTkinter 构建原生桌面界面
- NumPy 负责程序化合成，SoundFile 与 LAME 负责音频编码
- JSON 保存工程数据，SQLite 保存操作历史
- PyInstaller 构建 macOS / Windows 应用

## 性能目标

- 安装包小于 80 MB
- 空工程内存低于 150 MB
- SSD 冷启动少于 3 秒
